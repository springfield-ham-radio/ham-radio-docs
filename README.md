# ham-radio-docs

VitePress documentation for [HamBench](https://github.com/springfield-ham-radio).

Published site: <https://springfield-ham-radio.github.io/ham-radio-docs/>

## Develop

```bash
yarn install
yarn dev
```

Requires Node.js 24 (see `.nvmrc`). The site is served at `/ham-radio-docs/` to match GitHub Pages.

```bash
yarn build
yarn preview
```
